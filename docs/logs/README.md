## 记录原则

- 只记录开发过程、决策和验证结果，不上传 Token、密码、地图 AK、完整手机号等敏感信息。
- 原始后端运行日志和浏览器调试日志不进入仓库，仅保留整理后的 Markdown 记录。
- 技术栈与接口发生变化时，先更新项目根目录的 `AGENTS.md`，再补充本目录日志。
