# 2026-11-18：环境搭建与项目计划

## 目标

完成校园快递点导航与空闲度查询平台的本机开发环境、项目骨架和毕业设计计划。

## 已完成

- 部署 JDK 21、Maven 3.9.16、Node.js 22、Git、MySQL 8.4.4 等便携工具链。
- 创建 Spring Boot 后端与 Vue 3 前端工程骨架。
- 确认后端健康检查、数据库连接和前端构建可用。
- 完成毕业设计项目计划书修订版，规划 9 个业务模块、9 张数据表和 47 个初始业务接口。
- 明确三类角色：学生、站点管理员、超级管理员。

## 关键决策

- 按物理站点管理数据，站点与快递公司采用多对多关系。
- 包裹状态采用“待取、已取、已撤销”三态。
- 拥挤度采用学生上报和站长校准，并按时间衰减计算 0—100 指数。
- 地图统一使用百度地图 JS API GL 版。
- 不使用 Spring Security，鉴权采用 JWT 拦截器。

## 验证

- 后端可启动，健康检查能够连接 MySQL。
- 前端依赖安装完成，基础构建通过。

## 遗留问题

- 数据库表结构、实体和接口需要继续落地。
