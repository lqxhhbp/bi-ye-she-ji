# P5 全链路演示脚本

本脚本用于毕业设计答辩演示准备。本轮只准备脚本，不实际录屏。

## 1. 演示准备

- 启动 MySQL、后端和前端，确认 `http://localhost:8080/api/health` 返回 `dbOk=true`。
- 打开前端 `http://127.0.0.1:5173`。
- 演示账号密码均为 `123456`：
  - 学生：`13800002001`
  - 顺丰站点管理员：`13800001001`
  - 超级管理员：`13800000000`
- 如需恢复初始演示数据，执行 `campus-express/src/main/resources/db/seed_p3_demo.sql`。
- 当前百度 AK 仅支持浏览器端地图。百度 Web 服务接口返回状态码 `240：APP 服务被禁用`，演示时不要切换到后端 Web 服务方案。

## 2. 推荐演示顺序

### 场景一：学生登录与查件

1. 使用学生账号登录。
2. 在查件页输入手机号 `13800002001`，展示待取包裹列表。
3. 打开任一包裹的“时间线”，说明包裹上架、撤销和核销流水。
4. 切换到“我的”，进入“我的包裹”，展示全部、待取、已取和已撤销筛选。

预期：学生只能看到本人手机号对应的包裹，手机号已脱敏。

### 场景二：地图路线与拥挤度

1. 打开“地图”页。
2. 选择“拼多多驿站京东快递”等站点。
3. 展示校园中心到站点的步行路线、距离和预计时间。
4. 切换到“驾车”，展示路线和时间变化。
5. 点击“上报”，选择“空闲、一般、拥挤”之一提交现场反馈。

预期：地图显示 5 个站点，绿、黄、红分别表示空闲、一般和拥挤；步行与驾车路线均能绘制。

### 场景三：站长包裹管理

1. 切换顺丰站点管理员账号。
2. 在工作台展示今日上架、待取、已取、撤销和近 7 天趋势。
3. 打开“包裹列表”，展示状态、关键字和分页筛选。
4. 打开“包裹录入”，演示取件码、手机号、快递公司和货架号表单。
5. 打开“批量导入”，展示模板下载和 Excel 上传区域。
6. 进入“取件核销”，输入待取包裹取件码，确认包裹详情后核销。

预期：站长只能访问本站数据；核销成功后包裹状态变为已取并写入流水。

### 场景四：学生再次查件

1. 切回学生账号。
2. 查看刚刚核销的包裹已从待取列表移出。
3. 在“我的包裹 → 已取”中查看核销记录。

预期：上架、核销、查询形成完整状态闭环。

### 场景五：超管运营管理

1. 切换超级管理员账号。
2. 在统计看板切换 7/14/30/90 天范围，展示站点吞吐、拥挤度分布和操作员工作量。
3. 在站点管理中打开编辑站点，输入地址后点击“地址解析坐标”，展示经纬度回填和地图预览。
4. 展示代理快递公司维护、入驻审核、告警处理和操作日志分页。

预期：超管可查看全平台数据并进行站点、品牌、审核和告警管理。

## 3. 建议时长

| 场景 | 建议时长 |
|---|---:|
| 项目背景与架构简述 | 40 秒 |
| 学生登录、查件与历史 | 60 秒 |
| 地图路线与拥挤度上报 | 60 秒 |
| 站长上架、列表与核销 | 70 秒 |
| 学生确认核销结果 | 20 秒 |
| 超管统计、地图解析与审核 | 70 秒 |
| 总结 | 20 秒 |

总时长建议控制在 5—6 分钟。

## 4. 演示注意事项

- 演示前关闭无关浏览器标签和通知。
- 不在视频中展示 `.env.local`、Token 或完整手机号。
- 先完成核销，再展示学生“已取”记录，顺序不要颠倒。
- 如空闲度上报被限频，恢复演示数据或更换未上报账号。
- 录屏时以桌面宽度展示站点端和超管端；学生端可切换手机视口展示。
